## Reproduce assets

From the Aether worktree root:

```sh
python3 docs/landings/aether-story/generate-art.py
bun run dev --host 127.0.0.1 --port 5184 --strictPort
# In a second terminal (requires installed Google Chrome):
node docs/landings/aether-story/qa/render-assets.mjs
```

The first script reproduces original vectors. The second renders the same procedural 3D used in production. It writes only Aether's poster and catalog preview. Font binaries and their OFL files are checked in; no font download is needed at build or runtime.

## Matching crystal studies (2026-10-26)

`sonora-crystal.webp`, `vela-crystal.webp`, `verdant-crystal.webp` and their `-awakened.webp` variants are original images rendered from the same live Three.js scene, physical materials, environment and camera as the interactive gallery. Generate with `AETHER_QA_URL=http://127.0.0.1:5184/ node docs/landings/aether-story/qa/render-crystals.mjs`. Browser-native WebP encoding uses quality 0.99. Both modes share the same 5:4 projection and normal/discovered colour states. No external artwork or texture is used.

The current HDR highlight/blur/composite pipeline in `bloom.ts` is original repository code. It uses no additional runtime package. Prismatic Glass and the palette controls were removed; current finish/preset details are in [refinement.md](refinement.md).
