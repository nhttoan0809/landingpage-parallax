This repository vendors the skill instructions, references, data, and Python
runtime scripts. Upstream repository maintenance tests and their fixtures are
excluded because they require files outside the standalone skill.

Local adaptations:

- Install under `.agents/skills/ui-ux-pro-max/` for Codex repository discovery.
- Use `python3` and an explicit `<repo-root>/.agents/skills/...` script path in
  `SKILL.md`, replacing the Claude plugin environment variable.
- Ignore Python bytecode generated by the search scripts.

Requires Python 3; no third-party Python packages are needed. Run from the repo
root to verify the installation:

```bash
python3 .agents/skills/ui-ux-pro-max/scripts/search.py "reduced motion" --domain ux
python3 .agents/skills/ui-ux-pro-max/scripts/search.py "memo" --stack react
python3 .agents/skills/ui-ux-pro-max/scripts/search.py "photography portfolio cinematic" --design-system -p "Skill check"
```

These commands print recommendations without persisting a design system.
